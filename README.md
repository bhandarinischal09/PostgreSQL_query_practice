SQL Data Analysis Projects
📌 Project Overview

This repository contains two SQL projects developed using PostgreSQL to practice data analysis, querying, and database management.

🏥 1. Hospital Analysis

Analyzes hospital data to explore patient counts, doctor availability, department performance, patient stay duration, and medical expenses.

Files: Hospital_datas.csv, Hospital_queries.sql

📚 2. Online Book Store

Analyzes bookstore data to explore book inventory, sales revenue, customer purchasing behavior, popular books, and order trends.

Files: Books.csv, Customers.csv, Orders.csv, 14 - PROJECT.sql

🛠️ Tools & Technologies
PostgreSQL
SQL
CSV datasets

🎯 Objective

To develop practical SQL skills using real-world-style datasets and solve analytical problems using filtering, aggregation, joins, subqueries, and date functions.
